기획안에는 PaddleOCR·SAM 2, AI 문의 답변, 서버 이미지 캐시 등 후속 기능도 포함됩니다. 현재 MVP의 AI 기능은 **Tesseract.js 기반 영문·숫자 OCR**이며, 4행×5열의 규칙 좌석 배치와 운영자 치수 입력으로 3D 모델을 구성합니다. 기획상의 기능을 모두 구현했다는 의미는 아닙니다.

공연장·예매 플랫폼과의 협업은 제안 단계입니다. 실제 제휴, 현장 시야 정확도, 매출·문의 감소 효과를 검증한 자료는 아닙니다.
